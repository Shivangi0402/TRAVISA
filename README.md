TRAVISA – Demo Visa Booking Portal

A full-stack web application that simplifies visa booking and management. TRAVISA provides users with a smooth experience to browse services, book securely with a Razorpay demo checkout, and receive automated email confirmations. It includes features for authentication, service management, and bookings — making it a real-world style project for learning full-stack development.

🚀 Features

🔐 User Authentication – Register & login with form validation

🗂 Service Management – Browse available visa services + add new services

💳 Payment Integration – Razorpay demo checkout for secure payments

✉️ Email Notifications – Nodemailer sends booking confirmations automatically

🗄 Database – MySQL schema for Users, Services, and Bookings

📦 File Handling – Multer for handling uploads

🎨 Responsive UI – Built with React for a clean and user-friendly design

🛠️ Tech Stack

Frontend:- React.js, HTML, CSS, JavaScript

Backend:- Node.js

Database:- MySQL

Integrations:- Razorpay (Payments), Nodemailer (Emails), Multer (File uploads)
